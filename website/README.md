# 📊 Grit Intelligence Dashboard

The visual companion to the Grit CLI. This Next.js application provides an elite web-based dashboard for visualizing your Git metrics, streak health, and commit velocity.

## 🛠 Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Components**: [shadcn/ui](https://ui.shadcn.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Visualization**: Custom SVG and Mermaid diagrams for high-fidelity data representation.

## ✨ Features

- **Streak Visualization**: A high-impact view of your commit history and "Juice" levels.
- **Intelligence Pipeline**: See how your commits are being distributed across the timeline.
- **Real-Time Updates**: Syncs with the Grit CLI to reflect your latest work.
- **Elite Aesthetics**: Dark-mode first design with smooth animations and professional typography.

## 🚀 Local Development

Ensure you have `pnpm` installed.

1.  **Install Dependencies**:
    ```bash
    pnpm install
    ```
2.  **Start Development Server**:
    ```bash
    pnpm dev
    ```
3.  **Build for Production**:
    ```bash
    pnpm build
    ```

## 🔗 Connection to CLI

The dashboard consumes data generated by the `grit dash` command. It serves as a visual layer over the local state managed by the Grit Core Engine.

---

> [!TIP]
> The dashboard is designed to be lightweight and fast. It uses static exports where possible to ensure it can be served locally by the Python backend.
